KRAGEN2 is a litegraph.js based GUI with a python Flask backend.
It will use a python backend for LLM calls and any other heavy lifting, while the GUI is made with litegraph.js
litegraph.js has nodes to be able to display the graph of thoughts that are generated by the python backend.
Specifically the python backend uses the escargot pip package to generate thoughts and nodes, as well as the edges.
litegraph.js should be able to display this information nicely as well as assigning the edges
KRAGEN2 should also be able to run single nodes, step by step, to allow for a more interactive interface
there should also be a button to run the entire graph as well
